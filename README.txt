ROUNDABOUTS REFLECTIVE LOG - OFFLINE APP

FILES TO UPLOAD TOGETHER:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

INSTALL ON IPAD/IPHONE:
1. Upload all five files to the same HTTPS website/static host.
2. Open index.html in Safari.
3. Tap Share > Add to Home Screen > Add.
4. Open the Roundabouts Log icon once while online.
5. The app shell and pupil database then work offline.

DATA:
Pupil records and lesson logs are stored in IndexedDB on that device. They are not sent to the hosting website by this app. Use Backup Records regularly.

CONTACT EXPORT:
Each pupil profile includes Export All Logs, Email All Logs and Send to Mobile. Email/Messages/WhatsApp sending may require connectivity depending on the chosen app/service.
